# Online Complaint Management System

## Project Overview

The Online Complaint Management System is a web-based application developed for college students to submit and track complaints online.

Students can register, log in, submit complaints, and track their complaint status. Administrators can view complaints and update their status.

## Features

### Student Module
- Student Registration
- Student Login
- Student Dashboard
- Submit Complaint
- View Complaints
- Track Complaint Status
- Logout

### Admin Module
- Admin Login
- Admin Dashboard
- View Complaints
- Update Complaint Status
- Complaint Statistics
- Logout

## Technologies Used

## Complaint Status

- Pending
- In Progress
- Resolved

## Project Workflow

Student Registration
→ Student Login
→ Submit Complaint
→ Complaint Stored in Firestore
→ Admin Login
→ View Complaint
→ Update Status
→ Student Tracks Status

## Firebase

Firebase Authentication is used for student and admin login.

Cloud Firestore is used to store student and complaint information.

Firestore security rules are used to protect the application data.
